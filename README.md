## ✨ Features

- **Interactive Home Section** — Animated text, a 3D holographic character, and dynamic visual effects.
- **About Me** — An introduction to my background, interests, and technical skills.
- **Skills & Statistics** — Animated progress bars and interactive statistics.
- **Resume Timeline** — A visual overview of my education and professional experience.
- **Project Showcase** — Horizontally scrollable project cards with category filters, interactive previews, and GitHub links.
- **Contact Section** — A futuristic contact interface with an EmailJS-powered message form.
- **Bug Mode** — An interactive feature that adds a playful twist to the website.
- **Responsive Design** — Layouts adapted for desktop, tablet, and mobile devices.
